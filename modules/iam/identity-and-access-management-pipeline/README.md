# Identity and Access Management Pipeline Module

This module is sourced from the AWS AFT Blueprints repository (originally named `permission-set-pipeline`).

## How to populate

Clone the aft-blueprints repo and copy the module contents here:

```bash
git clone https://github.com/awslabs/aft-blueprints.git /tmp/aft-blueprints
cp -r /tmp/aft-blueprints/modules/iam/permission-set-pipeline/* .
rm -rf /tmp/aft-blueprints
```
